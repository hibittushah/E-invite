Kartik & Sangini — customized original invitation

index.html retains the original single-file invitation structure, embedded background images, logo, animation/reveal effects, opening gate, and embedded audio. It has been customized for Kartik & Sangini, 1–2 January 2027, Jaipur, and includes an RSVP form.

RSVP setup:
1. Create a Google Sheet.
2. Open Extensions > Apps Script and paste Code.gs.
3. Deploy > New deployment > Web app; Execute as: Me; Who has access: Anyone.
4. Copy the Web app URL.
5. In index.html, replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE with that URL.
6. Commit index.html to the GitHub Pages repository.

The RSVP responses will be stored in the Google Sheet under the tab “RSVP Responses”. The RSVP form is not connected until the Web app URL is configured.

Event times are carried over from the original reference: 1 Jan (8:15 AM, 11:15 AM, 2:15 PM, 6:15 PM) and 2 Jan (9:15 AM, 12:15 PM, 3:15 PM). The venue is currently shown as Jaipur, Rajasthan because the exact venue was not provided.
